# 本地开发环境（v0.1.0）

> 目标：**5 分钟内**从零启动后端 + 前端，默认可在没有模型 Key、没有 Redis、没有 Docker 的情况下跑通登录与 Mock 对话。

## 1. 前置要求

| 组件 | 版本 | 说明 |
| --- | --- | --- |
| JDK | 21 | `mvn -version` 确认 Java 21 |
| Maven | 3.9+ | 使用项目自带 `.mvn/settings.xml` |
| Node.js | ≥ 20（推荐 22/24） | `pnpm` 推荐 10.x |
| pnpm | ≥ 9 | `npm i -g pnpm` |
| 可选 MySQL | 8.0 | 生产形态；dev 默认 H2 文件库 |
| 可选 Redis | 7+ | 记忆引擎；无 Redis 自动降级内存实现 |
| 可选 Docker | 24+ | Docker 沙箱 / docker-compose |

Windows 用户若默认 `java` 指向 JRE 1.8：

```powershell
$env:JAVA_HOME='C:\Program Files\Java\latest\jdk-21'
$env:Path="$env:JAVA_HOME\bin;$env:Path"
```

## 2. 后端

```bash
mvn -DskipTests install          # 先 install 兄弟模块，spring-boot:run 才能解析 com.agentforge:* SNAPSHOT
mvn -pl agentforge-app spring-boot:run
# 或直接跑 fat jar（推荐，避免端口/依赖缓存干扰）
java -jar agentforge-app/target/agentforge-app-0.1.0-SNAPSHOT.jar
```

- 默认 profile：`dev`
- 数据库：H2 文件库 `./.data/agentforge`（首次启动 Flyway 建表）
- 地址：<http://localhost:8080>
- 健康检查：<http://localhost:8080/actuator/health>
- Swagger：<http://localhost:8080/swagger-ui.html>
- H2 控制台：<http://localhost:8080/h2-console>（JDBC URL `jdbc:h2:file:./.data/agentforge`，用户 `sa`，空密码）

默认 dev 账号由 `com.agentforge.app.config.DataInitializer` 幂等创建（**不是** Flyway 种子）：`admin@agentforge.dev` / `Admin@123456`（`AGENTFORGE_ADMIN_PASSWORD` 可覆盖，`AGENTFORGE_SEED_ADMIN=false` 可关闭）。

> 端口：8080 被占用时用 `--server.port=18080` 覆盖；跑端到端脚本时记得同步 `--base-url`。另外**别把其他进程的 8080 当成自己的服务**，先看 `/actuator/health` 返回的 `"status":"UP"` 再测试。

### 2.0 端到端冒烟（推荐）

后端启动后，在仓库根目录执行（Node 18+，零依赖）：

```bash
node scripts/smoke-test.mjs --base-url http://127.0.0.1:8080
```

覆盖：health、OpenAPI、登录、/auth/me、用户/角色/权限、登录日志、邮箱验证码、短信预留 50300、模型列表与连通性、审计 summary/trend/overview、Agent 创建、SSE 对话（校验 delta/completed 且无 error）、同步运行、工具列表、知识库上传→READY→检索、沙箱 Java 执行、数据源建/测/SELECT/DELETE 被拒、记忆事实。输出 `PASS/SKIP/FAIL` 计数，退出码 0/1，可用于 CI 或发布前回归。参数：`--account`、`--password`、`--jdbc-url`/`--db-user`/`--db-password`。

### 2.1 使用 MySQL（生产形态）

```sql
CREATE DATABASE agentforge DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

```bash
mvn -pl agentforge-app spring-boot:run -Dspring-boot.run.profiles=prod
```

环境变量：

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `AGENTFORGE_DB_HOST` / `_PORT` / `_NAME` | 否 | 默认 `localhost:3306/agentforge` |
| `AGENTFORGE_DB_USER` / `AGENTFORGE_DB_PASSWORD` | **是** | prod 不提供默认值，缺失则启动失败（故障关闭） |
| `AGENTFORGE_JWT_SECRET` | **是** | JWT 签名密钥，≥ 32 字节 |
| `AGENTFORGE_CRYPTO_KEY` | **是** | AES-GCM 主密钥（模型 Key / 数据源密码加密） |
| `AGENTFORGE_MAIL_ENABLED` | 否 | 默认 `true`，需同时配 `spring.mail.*` |
| `AGENTFORGE_REDIS_ENABLED` | 否 | 默认 `true`（prod 期望 Redis 可用） |

> prod profile 已强制 `seed-admin-enabled=false`、`expose-code-in-response=false`：默认管理员与 dev 验证码回显只在 dev 生效。

### 2.2 使用 Redis（可选）

```bash
# Docker（推荐）
docker run -d --name agentforge-redis -p 6379:6379 redis:7-alpine
```

```bash
# 启用记忆引擎
AGENTFORGE_REDIS_ENABLED=true mvn -pl agentforge-app spring-boot:run
```

无 Redis 时：`agentforge.memory.redis-enabled=false`（默认），记忆走 `InMemoryMemoryStore`，进程重启后丢失。

> Windows 无 Docker 时可尝试 Redis for Windows（msys2 版）或 Garnet；受限环境（禁止命名管道）下可能无法启动，此时保持内存降级即可，参见技术方案第 9 节。

### 2.3 配置模型（可选）

后台默认使用内置 `MOCK` 模型（返回固定回复并模拟 token usage），便于零 Key 联调。切真实模型：

1. 启动后登录控制台 →「模型配置」→ 新建：`provider=DASHSCOPE`、`modelName=qwen-plus`、`apiKey=sk-xxx`、`defaultModel=true`；
2. 或直接调 API：`POST /api/v1/models`（`permission: model:write`），Key 由服务端 AES-GCM 加密入库，响应仅返回 `hasApiKey`；
3. 主密钥用 `AGENTFORGE_CRYPTO_KEY` 覆盖（默认值仅供本地开发，生产必须替换）。

> `AI_DASHSCOPE_API_KEY` 只用于满足 Spring AI Alibaba 自动配置的启动校验（`application.yml` 里是 `sk-agentforge-development-placeholder`），**模型网关不会读取它**——不设也能启动，真实调用以「模型配置」里的 Key 为准。

### 2.4 邮箱验证码

默认 `agentforge.auth.mail-enabled=false`，验证码打印到后端日志（`INFO  com.agentforge.security...`）。配置 SMTP 后自动真实发送：

```yaml
spring.mail.host: smtp.example.com
spring.mail.port: 465
spring.mail.username: no-reply@example.com
spring.mail.password: ******
agentforge.auth.mail-enabled: true
```

## 4. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| `mvn` 下载依赖卡住/失败 | 确认为项目根目录执行（`.mvn/maven.config` 生效）；必要时删除 `.m2repo` 重试 |
| `AccessDeniedException: D:\MavenRepository` | 使用了全局 settings；本项目 `mvn` 会自动改用 `.m2repo`，勿加 `-s` 覆盖 |
| Flyway 报 `Validate failed` | 开发期改过迁移文件：删除 `.data/` 后重启（**已提交的迁移文件不得修改**） |
| 8080 被占用 | `server.port` 或 `-Dspring-boot.run.arguments=--server.port=8081` |
| SSE 无响应 | 反向代理需关闭缓冲（Nginx `proxy_buffering off`） |
| 无 Docker 时沙箱 | 自动使用 Process 沙箱（受限权限 + 超时），README 有风险声明 |
